# 樱川漫游

把 Sakura Crossing 的开放场景扩展为可选择路线、记录发现的中文散步体验。

## 运行

需要 Node.js 18 或更新版本。首次运行 `npm ci`，然后 `npm run play`。
体验地址为 http://127.0.0.1:5179/。开发使用 `npm run dev`。

## 新体验

- 直接以实时场景作为首页背景，配合中文旅行手册界面。
- 三条可选择的路线：第一次来小镇、听风的散步、向山里去。
- 六个可到访地点：踏切、商店街、图书馆、神社、河岸和山间展望台。
- 地图展示当前位置；地点可设为目的地，方向和直线距离实时更新。
- 进入地点范围后自动记录发现，同一地点不会重复计数；进度保存在当前浏览器。
- 路线内的当前地点到访后自动切换到下一站。
- 首次加载提示、操作说明与适应窄屏的首页和地图。

地图提供目的地方向，并非绕开建筑的道路规划。键盘与鼠标漫游需要电脑；手机可以查看首页和手册。

## 操作

WASD 移动，鼠标转向，Shift 加速，E 互动，V 电动车，P 星球视角，M 音乐，R 回到起点。
漫游时按 Tab 打开地图；Esc 暂停并释放鼠标。在首页或暂停页可查看操作说明、选择路线、调整音量。

## 验证

`npm test` 验证地点发现、存档恢复与方向计算。
`npm run build` 构建生产版本。
启动生产预览后，`npm run test:browser` 验证真实页面的地图、进度持久化、漫游、键盘操作与窄屏布局。
浏览器检查默认使用本机 Microsoft Edge；也可设置 `PLAYWRIGHT_CHANNEL` 来选择已安装的浏览器。
`APP_URL` 可以指定其他预览地址。
